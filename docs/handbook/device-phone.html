它能做什么

与两代"语音伴侣"不同，话机的核心是通话：它不在设备上跑对话模型，而是把声音原样接进酒店电话系统，由 AI 前台（或转接后的人工坐席）接听。

📞一句话找前台

"帮我找下前台""送两瓶水""空调坏了"这类需要人处理的事，小安会说"正在为您接通"，然后自动拨通前台号码（默认 8888），接通后免提通话，挂断后回到对话。拨号盘里的绿色按钮也能直接呼叫。

🗣️语音唤醒 + 自由对话

休眠时本地识别"你好小安"（乐鑫官方模型，不联网不上传）。醒来后直接连上千问实时语音模型，像和人说话一样提问、追问、打断，不用背固定指令。

✋免提双向可打断

板载双麦克风 + 硬件回声参考通道 + 乐鑫 AEC 算法，喇叭放得再响也不会把自己的声音传回去；AI 说话时你可以直接插话。

🔢手动拨号盘

设置页里藏着完整的 12 键拨号盘，可以拨任意分机或号码（需服务器侧放行），不只是前台。

📲可接来电

注册模式下前台或坐席可以回拨客房，设备振铃、屏幕显示来电方，点绿色接听、红色拒接。

👀有表情的待机脸

待机时显示一双会眨眼、会跟手指看的眼睛，顶部时钟、底部电量。被唤醒后眼睛的表情会跟着状态变（倾听、思考、说话、困倦）。

🔊音量与亮度

通话中按钮调音量，待机时语音调音量和亮度，设置页里有整行滑条。亮度最低 20%，不会调到全黑。

📶手机配网

首次使用用手机连设备热点，网页里选 Wi-Fi 输密码即可。同一网页还能改前台号码、本机号码、音量等，局域网内随时可打开。

🔋电池可选

Type-C 供电；BOX 版内置电池，可移动放置。屏幕底部显示电量，低于 20% 变红。

和语音伴侣的区别一句话：语音伴侣把你的话送给云端大模型"聊天"；话机把你的声音接进电话线，由前台接听。两者可以同时放在客房里，一个负责问答，一个负责找人。

快速上手

首次开机到第一次通话，大约两分钟。

通电开机

Type-C 接通电源。屏幕显示启动画面，几秒后进入待机脸。未配置 Wi-Fi 时自动进入配网模式，屏幕显示"配网模式"和热点名称。

手机连接设备热点

热点名 AICC-Phone-XXXX（XXXX 为设备编号，印在屏幕上），密码 12345678。

选择 Wi-Fi 并提交

手机会自动弹出配置页（没弹出就在浏览器打开 192.168.4.1）。页面列出附近的 2.4 GHz Wi-Fi，点选一个，输入密码，点"连接并保存"。页面实时显示连接结果。

自动进入待机

联网成功后设备进入待机脸，顶部出现时钟，热点在 45 秒后自动关闭。设备随即向电话服务器探测连通性，此后便可拨号。

第一次对话

先在配置页填好 DashScope API Key（见"网页配置页"）。对着设备说 "你好小安"，听到上扬提示音、屏幕亮起后，小安会先问候一句；直接说"帮我找前台"或"声音小一点"试试。说完点屏幕任意位置可挂断电话；两分钟没人说话设备自动休眠。

配网只需做一次。设备记住 Wi-Fi 后每次开机自动联网；Wi-Fi 暂时不可用时会每 30 秒自动重试。仅支持 2.4 GHz Wi-Fi。

语音唤醒与对话

唤醒词在设备本地识别（乐鑫 WakeNet9 "你好小安"），不需要网络、不上传声音。唤醒后的对话由阿里云百炼 qwen-audio-3.1-realtime-flash 实时语音模型完成，设备直接连接模型，没有固定指令表。

1休眠

屏幕黑着，只有麦克风在听唤醒词。Wi-Fi 和电话线路仍然在线，前台回拨照样能响。

2唤醒

说 你好小安，设备播放上扬双音、屏幕亮起，连接语音模型，小安先问候一句"您好，有什么可以帮您？"

3对话

直接说话即可，不用再喊唤醒词。小安说话时眼睛换成"说话"表情，回复文字显示在眼睛下方；它说到一半你也可以直接插话。

4休眠

连续 2 分钟双方都没说话，或你说"没事了/再见"，设备道别后关屏休眠，回到只听唤醒词的状态。

小安能做什么

小安是客房里的通用知识助手：常识、历史、经济、人文、天文地理、科技、旅行、语言都能聊，也能算数、翻译、出主意。 酒店自己的业务（早餐与退房时间、房价账单、送物维修、投诉叫车、转人工）不归它管——那属于前台，由电话那头的酒店客服 AI 回答。

提示音含义：上扬双音 = 听到唤醒词、正在连接；短促单音 = 已执行（按键音）；下落单音 = 连接失败或休眠。

常见问题

遇到问题先看这里。

喊"你好小安"没有反应

确认设备在待机脸（通话中不响应唤醒词）。四个字连读，"安"字读清楚，正常音量、1 到 2 米；等 2 秒再喊第二遍。电视声或多人同时说话会降低识别率。可在网页配置页把"唤醒灵敏度"改为"宽松"。若设置页能正常用而唤醒始终无效，可能是模型分区未烧录，联系维护人员。

没人说话它自己醒了

偶发属正常（官方指标约 12 小时 1 次）。频繁误唤醒时在网页配置页把"唤醒灵敏度"改为"严格"，或让设备远离电视、空调出风口。

唤醒后屏幕显示"语音助手暂不可用"

设备连不上百炼：检查 Wi-Fi 能否上外网、配置页里的 API Key 是否正确、接入地址是否填错。20 秒后设备自动休眠，修好后再喊一次即可。

唤醒后显示"未配置 API Key"

到网页配置页"语音助手"卡片填入 DashScope API Key，保存后设备重启生效。

拨号后提示"号码不存在"

前台号码（DID）在电话系统里没有配置，或填错了。到网页配置页核对"前台号码"，或在电话系统后台确认该号码已分配给 AI 前台流程。

拨号后一直"正在呼叫..."然后失败

设备到服务器的 SIP 不通。看设备信息页的 SIP 状态：显示"网络断开"是 Wi-Fi 问题；显示"直连模式"但仍失败，检查服务器地址/端口，以及所在网络是否拦截了 UDP 5060/5080 和 20000 端口。

对方说听到回声或自己的声音

正常情况不会。确认网页里 AEC 没有被关闭；把设备放在不紧贴硬墙的位置；音量不必开满。若仍有，把"参考通道软件增益"从 4 降到 2 试试。

喇叭声音卡顿

多为 Wi-Fi 信号弱或公网抖动。设备有 80 到 400 毫秒的自适应缓冲；若仍卡顿，让设备靠近路由器，或检查路由器是否限速。

屏幕一直在配网页，手机连不上热点

热点名以 AICC-Phone- 开头，密码 12345678。连上后若没自动弹页面，手动打开 192.168.4.1。注意手机不要自动切回蜂窝数据。只支持 2.4 GHz Wi-Fi。

换了路由器怎么办

设置页 → 重新配网，点两下确认，设备重启进入配网模式，按快速上手重新操作。前台号码等 SIP 设置会保留。

可以打其他分机吗

可以。拨号盘上直接输入分机号再按绿色按钮。能否接通取决于电话系统的拨号规则：直连模式下只能拨系统对外公开的号码；注册模式下可以拨内部分机。

后面还能在它上面做什么

话机已经把"语音入口 + 电话线路 + 屏幕"三件事打通，下面这些扩展都只需要改固件或后台配置，不用换硬件。

可直接做

更多工具与知识

给小安加工具只是加一段 JSON 和一个处理分支：叫客房服务拨到服务队列、查天气、报时、定闹钟；酒店知识直接写进配置页的"酒店信息"，不用改固件。

可直接做

一键服务按钮

待机脸下方加一排图标（前台 / 送餐 / 保洁 / 叫车），点一下直接拨对应号码，老人和不习惯语音的客人也能用。号码表由后台下发，不同楼层、不同房型可以不一样。

可直接做

房号身份与来电显示

配网时填房号，设备以房号注册为分机。前台来电时屏幕显示"前台"，前台那边一看就知道是哪间房打来的，和酒店 PMS 的房态联动也有了钥匙。

近期

DTMF 按键音与 IVR

通话中弹出数字键盘发送 DTMF，可以操作电话系统里的按键菜单、输入房号或验证码；同时支持保持、转接。

近期

闹钟与叫醒服务

设备有 RTC 时钟和喇叭。客人说"你好小安，明早七点叫我"，或前台在后台下发叫醒任务，到点由设备本地振铃，不占用电话线路；也可到点自动拨通前台做人工叫醒。

近期

通知与消息推送

后台通过 SIP MESSAGE 或 HTTP 给设备推文字：早餐时间、退房提醒、天气、快递到了。屏幕弹卡片、喇叭轻响一声，客人点一下确认。

近期

多语言唤醒与界面

小安本身支持多语言对话（跟随客人的语言回答）；乐鑫也提供英文唤醒词模型，可为外宾房间换成 "Hi ESP" 一类的英文唤醒词；界面文字已集中管理，换语言只需换一张字符串表并重新生成字体。

可直接做

经服务器中转

把设备对百炼的连接改为经酒店服务器中转：API Key 不再存在设备里，提示词、工具、房号身份集中管理，对话记录可随转人工一起交给坐席，并与 aicc 的队列、工单打通。

规划

视频与对讲

圆屏可显示前台摄像头画面或门口访客；配合酒店门禁，客人在房内看到来访者并一键开门或拒绝。

规划

批量部署与远程运维

后台看到每台话机的在线状态、信号强度、固件版本；一键远程重启、推送固件（OTA 分区已预留），配网信息可按楼层批量预置，免去逐台手机配网。

规划

氛围与客房控制

待机脸之外，屏幕可做床头小时钟、天气、房间温度；通过本地网关联动灯光、窗帘、空调，"小安，关灯"由工具调用交给本地网关执行。
